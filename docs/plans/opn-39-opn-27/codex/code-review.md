## Re-verification

All three original MAJOR findings are resolved.

- **MAJOR 3 — resolved.** `mention_shape_error` checks absolute paths first, then splits the unmodified string and rejects `..`, empty, and dot-prefixed segments before constructing `PurePosixPath` (`server/app.py:91-114`). The order is correct and load-bearing: `/etc/passwd`, `//server/share/x.mp4`, and Windows absolute paths receive the absolute-path error before their leading empty segment can win; `assets/./video/hook.mp4`, `assets//video/hook.mp4`, and `assets/video/../hook.mp4` are rejected on raw shape; only after those exclusions is `PurePosixPath` normalization harmless. The endpoint tests use real existing files and assert both 422 and zero runner calls.
- **MAJOR 2 — resolved.** `hasWholeToken` requires whitespace or string boundaries on both sides of an occurrence (`web/src/chat/mentions.js:137-142`), so suffix edits, prefix/prepend edits, and nested suffixes no longer retain a stale sidecar. I accept the documented trailing-punctuation false negative. A filename may legally contain the same punctuation, so treating punctuation as a boundary would recreate the wrong-file risk; selection already inserts a trailing space, and dropping an ambiguous reference is the safer, simpler ceiling than introducing rich token-range state.
- **MAJOR 1 — resolved.** `send` returns false for non-delivery and true for a completed or user-stopped turn (`web/src/chat/useAgentChat.js:120-220`), while `submitTurn` waits for that result and retires only the tokens actually sent (`web/src/chat/ChatPanel.jsx:108-117`). Treating user stop as delivered matches the existing contract: the stop branch deliberately does not restore the draft, and retaining a sidecar after its visible text is cleared would create a new desynchronization. The functional state update filters the current reference set, so distinct references added after the captured send set are not cleared. The newer-draft guard remains unchanged at `web/src/chat/useAgentChat.js:206-208` and its regression test remains green.
