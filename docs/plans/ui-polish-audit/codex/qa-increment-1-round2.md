## New findings

1. **Blocking — the render percentage fails AA on its actual dark surface.** `.render-progress` establishes `--pre-bg: #1e1c18` and `--on-dark` (`web/src/styles.css:395-399`), but `.rp-pct` overrides its 12px text to `--ink-dim: #6f665c` (`:405`). The WCAG sRGB ratio is 3.022:1; `--on-dark: #d8d0c4` would be 11.129:1. Claude should either inherit `--on-dark` now or pull the Phase 4 indeterminate-state replacement forward. This is the only newly found contrast defect.

2. **Nonblocking test gap — the toolbar test checks structure, not overflow behavior.** `StudioToolbar.test.jsx:38-47` asserts that More and `.st-grp-optional` exist, but jsdom applies no container queries and the test never establishes a viewport, checks computed visibility, or proves Save/Export remain on one line. Its own comments acknowledge this limitation (`:27-30`, `:85-86`). The coordinator's real 960px probe is the evidence that B5/V2 works today; the unit test would not catch a future breakpoint or clipping regression. Add a Playwright geometry assertion when browser QA is available, but this gap alone does not block this round.
