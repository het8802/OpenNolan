# Script Director — instagram-reels-studio

Produce the `script` artifact for a vertical short-form reel. Reel pacing, not explainer pacing.

## Rules

- **Hook in the first 2 seconds.** The opening line/visual must stop the scroll. Write it first.
- **Short beats.** One idea per beat; punchy, spoken-aloud phrasing. No long sentences.
- **Caption-friendly.** Lines should read well as word-by-word or sentence captions.
- **Tie beats to planned moves.** If the brief flagged a cutout, keyframe reveal, beat-drop cut,
  freeze on the punchline, or a restyled hero shot, mark which beat each lands on so the scene
  and edit stages can place them.
- **End on a CTA or loop.** A reason to follow, comment, or rewatch.

## If repurposing source footage
Use `transcriber` to pull the transcript, then select the most clip-worthy 7–30s window and
write the script around it (don't start or end mid-sentence).

## Quality bar
Strong 2-second hook, short beats, caption-ready lines, beats annotated with the planned
Edits-style moves. Checkpoint for human approval.
