# Het OpenAI Finance Talking-Head → Screen-Demo Adaptation

Session reference for adapting raw talking-head footage into the Clicko-style proof/demo reel system.

## Source footage
- `IMG_2494.MOV`: 85.55s, 1080×1920, main talking-head take.
- `IMG_2490.mov`: 4.62s, 1080×1920, short retake/opening line.

## Topic transcript summary
OpenAI launched a personal finance preview for ChatGPT Pro users in the U.S. Users can connect financial accounts through Plaid, view a dashboard, and ask ChatGPT questions grounded in spending, subscriptions, investments, and goals. The bigger thesis: consumer AI is moving from generic chatbot advice to connected real data + memory + dashboard + trust/approval + domain workflow.

## Visual diagnosis
- Footage is already vertical and usable as creator layer.
- Static bedroom/white-wall background with blinds and a visible ceiling vent. Crop/push in 112–118% to reduce ceiling/vent and place eyes near upper third.
- Het holds a small mic near mouth throughout. This reads creator-native but can feel static if left full-screen too long.
- Lighting is cool/flat compared to the warm reference desk setup; add slight warmth/contrast.
- Best use: full-screen Het only for hook, thesis, and CTA. Most middle should become screen footage or proof cards with Het as PIP.

## Required proof/screen assets
1. OpenAI article screenshot: `https://openai.com/index/personal-finance-chatgpt/`
2. Plaid article screenshot: `https://plaid.com/blog/chatgpt-personal-finance-plaid/`
3. ChatGPT/Finances sidebar or reconstructed UI mock.
4. Personal finance dashboard mock: spending, subscriptions, investments, upcoming payments.
5. Diagram: `Model + Connector + Memory + Trust + Workflow`.
6. Final builder checklist card.

## Caption chunks
Use short stressed phrases, not full subtitles: `PERSONAL FINANCE`, `REAL ACCOUNTS`, `PLAID`, `NOT BUDGETING TIPS`, `PERMISSION ACCESS`, `REAL PERSONAL DATA`, `MEMORY LAYER`, `TRUST LAYER`, `SENSITIVE CONTEXT`, `BLANK CHATBOT`, `COMMENT FINANCE`.

## Reusable lesson
When the provided footage is only talking head, do not merely caption it. Convert the middle into a proof/demo reel by extracting claims, mapping each claim to a source/UI/diagram asset, then using the creator as full-screen anchor only at hook/thesis/CTA and as large PIP over proof footage for the body.
