## Findings & actions this run

### 1. Homepage had no FAQ section or FAQPage schema — FIXED (P1 from last run)
- **Impact:** High. The homepage is the highest-authority page and where signup intent peaks. No on-page objection-handling, and no homepage-level `FAQPage` schema for AEO.
- **Fix:** Added a 6-question FAQ section (`#faq`) before the final CTA — StoryBrand objection-handling (what is it / can I download yet / cost / do I need editing skills / what the agent does / privacy), with a scoped style block matching the warm editorial aesthetic (card bg, coral chevron, Fraunces questions, 760px column). Added a matching `FAQPage` node to the homepage JSON-LD `@graph` (now Organization + WebSite + SoftwareApplication + FAQPage). Answers in HTML and schema are identical.

### 2. `how-to/tiktoks` — latent content bug: steps were invisible — FIXED
- **Impact:** High (content + schema). The 5 well-written steps were authored **nested inside `sections[1]`** instead of at the top level, so `renderSections` silently dropped them — they never rendered on the live page, and the page got **no HowTo schema** (the only how-to page missing it).
- **Fix:** Moved `steps` + `stepsHeading` to the top level (where `renderPage`/`jsonldFor` read them) and removed the now-redundant wrapper section. Result: the 5 steps now render as a proper ordered list, and `tiktoks` earns HowTo schema. **All 7 how-to pages now have HowTo schema.**

### 3. Everything else: still clean
- 30 pages (+ homepage) validate: unique in-budget titles, unique canonicals, 1 H1/page, valid JSON-LD, **0 dead internal links**.
- robots.txt AI-crawler welcome, llms.txt/llms-full.txt/pricing.txt all present.
- StoryBrand: homepage still hits all 7 SB7 elements; FAQ adds the "overcome objections" beat at the point of conversion.
